# Automystics — VPS Deployment (Ubuntu 22.04 / 24.04)

Stack: **Nginx (static + reverse proxy) + PM2 (Node API) + local PostgreSQL**.

---

## Quick start (first time)

Clone the repo onto the server, then run the one-time setup script:

```bash
git clone https://github.com/your-org/automystics.git /var/www/automystics
cd /var/www/automystics
sudo bash deploy/setup.sh
```

The script will prompt for:

- **PostgreSQL password** — used for the `automystics` DB user it creates
- **Admin password** — for the `/admin` login (leave blank to use the built-in default; change before going live)
- **Domain or IP** — e.g. `automystics.com` or your server's public IP (used in Nginx config)
- **HTTPS via Let's Encrypt** — only works if DNS is already pointing at this server

It then installs all dependencies, builds the API and frontend, pushes the database schema, configures Nginx, and starts the API under PM2.

---

## Deploying updates

After setup, every code update is a single command:

```bash
cd /var/www/automystics
bash deploy/deploy.sh
```

Add `--migrate` if the database schema changed, or `--branch <name>` to deploy a specific branch:

```bash
bash deploy/deploy.sh --migrate
bash deploy/deploy.sh --branch staging
```

---

## What each file does

| File | Purpose |
|---|---|
| `deploy/setup.sh` | **One-time** server setup — installs packages, creates DB, writes `.env`, builds, configures Nginx + PM2 |
| `deploy/deploy.sh` | **Re-deploy** after a code update — pull, install, build, PM2 reload, health check |
| `deploy/ecosystem.config.cjs` | PM2 process definition for the API server |
| `deploy/nginx.conf` | Nginx site config — static frontend + `/api/` reverse proxy |
| `deploy/.env.example` | Template for `artifacts/api-server/.env` (generated by `setup.sh`) |

## Manual steps reference

If you prefer to run steps by hand (or need to troubleshoot), here are the equivalent commands for each stage.

### Server packages

```bash
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt-get install -y nodejs build-essential git nginx postgresql postgresql-contrib
npm install -g pnpm@9 pm2
mkdir -p /var/log/automystics
```

### PostgreSQL

```bash
sudo -u postgres psql <<'SQL'
CREATE USER automystics WITH PASSWORD 'CHANGE_ME';
CREATE DATABASE automystics OWNER automystics;
GRANT ALL PRIVILEGES ON DATABASE automystics TO automystics;
SQL
```

### Environment file

```bash
cp deploy/.env.example artifacts/api-server/.env
nano artifacts/api-server/.env   # fill DATABASE_URL, SESSION_SECRET, ADMIN_PASSWORD
chmod 600 artifacts/api-server/.env

# Generate a strong session secret:
openssl rand -base64 48
```

### Build

```bash
pnpm install --frozen-lockfile
pnpm --filter @workspace/api-server build
PORT=8090 BASE_PATH=/ pnpm --filter @workspace/automystics build
```

### Database schema

```bash
pnpm --filter @workspace/db exec drizzle-kit push --force
```

### Nginx

```bash
cp deploy/nginx.conf /etc/nginx/sites-available/automystics
sed -i 's/YOUR_SERVER_IP_OR_DOMAIN/your.domain.or.ip/' /etc/nginx/sites-available/automystics
ln -sf /etc/nginx/sites-available/automystics /etc/nginx/sites-enabled/automystics
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
ufw allow 'Nginx Full'
```

### PM2

```bash
pm2 start deploy/ecosystem.config.cjs --update-env
pm2 save
pm2 startup systemd -u root --hp /root   # run the printed command as root
```

### HTTPS (after DNS is live)

```bash
apt-get install -y certbot python3-certbot-nginx
certbot --nginx -d yourdomain.com -d www.yourdomain.com
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| 502 from Nginx | `pm2 status` → `pm2 logs automystics-api`. Check port: `ss -ltnp \| grep 8080` |
| Session lost after login | Ensure Nginx forwards `X-Forwarded-Proto $scheme` (already in `nginx.conf`) and you're on HTTPS |
| Admin password not accepted | The default admin only seeds when `admin_users` is empty. Set `ADMIN_PASSWORD` before first boot, or wipe the table and restart PM2 |
| `BASE_PATH` / `PORT` build error | Both env vars must be set at build time: `PORT=8090 BASE_PATH=/ pnpm --filter @workspace/automystics build` |
| Cannot connect to Postgres | Check `pg_hba.conf` allows `127.0.0.1` md5 auth. Restart: `systemctl restart postgresql` |
| Email not sending | Go to `/admin` → Email Settings → save → "Send test email" |
